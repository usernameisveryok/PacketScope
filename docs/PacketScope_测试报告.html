1. 基于eBPF的网络数据包分析模块 (Analyzer)

1.1 IPv4/IPv6 地址转换与协议解析测试

测试项目IPv4/IPv6 地址转换与网络信息类型映射功能
测试目的验证 Analyzer 模块中 PSUtil 工具函数能够正确地将内核态 32 位整数、字节数组转换为人类可读的 IPv4/IPv6 地址字符串，以及网络信息类型 ID 到名称的正确映射。
测试环境本地 Python 3.12 环境，导入 modules/Analyzer/Monitor/PSUtil.py
测试步骤
  1. 调用 U32ToIpv4 函数，分别输入回环地址(0x0100007F)、全零地址(0x00000000)、广播地址(0xFFFFFFFF)、私有网络地址(0x0101A8C0)、A 类地址(0x0100000A)、非对称字节地址(0x04030201)；
  2. 调用 ArrayToIpv4 函数，分别输入 [127,0,0,1]、[0,0,0,0]、[255,255,255,255]、[192,168,1,1]；
  3. 调用 ArrayToIpv6 函数，分别输入回环地址、全零地址、全 FF 地址、fe80 链路本地地址、单字节填充地址；
  4. 调用 getInfoTypeName 函数，分别输入 0~3 及非法值 99、-1；
  5. 对比每个返回值与预期值。
预期结果
  1. U32ToIpv4 返回正确的点分十进制字符串：127.0.0.1、0.0.0.0、255.255.255.255、192.168.1.1、10.0.0.1、1.2.3.4；
  2. ArrayToIpv4 返回与 U32ToIpv4 一致的结果；
  3. ArrayToIpv6 返回冒号分隔的标准 IPv6 格式，且单字节十六进制值自动补零；
  4. getInfoTypeName 返回 netif_receive_skb_entry/exit、netif_rx_entry/exit，非法输入返回 "Illegal Code, Check Dev"。

1.2 系统 Socket 信息枚举测试

测试项目系统 Socket 信息读取与格式化输出
测试目的验证 ListSockets 模块能够正确解析 /proc/net/ 下的 TCP、UDP、ICMP、RAW 套接字信息和网络接口信息，并输出完整的 JSON 格式数据。
测试环境本地 Linux 系统，具有 /proc/net/tcp、tcp6、udp、udp6、icmp、icmp6、raw、raw6、dev 文件访问权限
测试步骤

  5. 验证 TCP 条目为 5 元组列表、dev 条目非空。
预期结果
  1. TranV4intoP("0100007F:0050") 返回 "127.0.0.1:80"；

  3. 所有 11 种 TCP 状态正确映射，未定义状态返回 "UNDEFINED"；
  4. ListAll 返回合法 JSON，包含全部 9 个分类键；
  5. 每个 TCP 条目为 5 元素列表，dev 至少有 1 个网络接口。

2.1 路由追踪参数校验与跳点分析测试

测试项目路由追踪核心功能：文件名安全过滤、DNS 解析、参数校验、跳点数据处理
测试目的验证 Tracer 模块的 tracer_service 能够正确进行文件名安全过滤（防止路径穿越攻击）、DNS 域名解析、traceroute 参数校验（协议类型、端口范围），以及跳点数据的延迟统计、丢包率计算、抖动估计和带宽评估。

  4. 非法协议/缺少端口/端口越界均抛出 ValueError 并包含准确错误信息；

2.2 路由异常检测与风险评分测试

测试项目路由路径异常检测与恶意 IP 风险评分
测试目的验证 analyze_anomalies 函数能检测路径偏移（新 IP 出现）和高延迟异常（>200ms 阈值），以及 guarder_risk_score 函数能正确对恶意 IP 库中的跳点进行风险评分。
测试环境本地 Python 3.12 环境
测试步骤
  1. 调用 analyze_anomalies，传入与历史一致的路由，验证无异常报告；
  2. 传入包含新 IP 的路由与历史记录，验证检测到 PathDeviation；
  3. 传入延迟 500ms 的跳点，验证检测到 HighLatency；
  4. 传入空历史记录，验证所有 IP 被标记为路径偏移；
  5. 测试延迟边界值 200ms（不触发）和 201ms（触发）；
  6. 调用 guarder_risk_score，传入正常 IP 列表，验证分数为 0；
  7. 传入空列表和 None IP，验证安全处理。
预期结果
  1. 一致路由无异常；新 IP 触发 PathDeviation 告警；
  2. 高延迟触发 HighLatency 告警，200ms 不触发，201ms 触发；
  3. 空历史下所有 IP 为新 IP，触发 PathDeviation；
  4. 正常 IP 风险分数为 0，无告警；空列表安全返回。
